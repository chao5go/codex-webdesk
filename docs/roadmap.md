# 迭代规划

定位：个人自托管的远程 Codex 工作台，覆盖任务执行、会话管理和本地工具插件。

- 0.1：npm 与 PyPI/uv 安装，同一套运行代码和版本；升级保持用户数据；隔离安装测试与发布流程。
- 0.2：doctor 环境诊断、init 配置初始化、多项目快捷切换。
- 0.3：历史索引与分页、任务日志清理和保留策略、数据备份导出。
- 后续：任务队列、插件管理命令、交互会话与审批适配。并发执行在目录竞争、取消与恢复行为验证后引入。

第一阶段仅支持 Linux/macOS；不承诺 Windows 进程树行为，也不自动安装或更新 Codex CLI。Go 分发暂不纳入范围。
